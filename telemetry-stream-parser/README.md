# telemetry-stream-parser

A fast parse-only library for workout telemetry: it ingests raw bytes, decodes FIT files, and emits a normalized event stream of timestamp/metric/value records for downstream analysis.

## What it does

This library reads a real Garmin workout binary, normalizes its record fields into a single event stream, and exposes a minimal async generator API. It intentionally stays focused on parsing bytes into machine-readable telemetry instead of app state, cloud sync, or UI concerns.

## Install

```bash
npm install
```

## Quick start

```ts
import { readFile } from 'node:fs/promises'
import { parseFile } from './src/index.js'

const file = await readFile('./sample.fit')
for await (const event of parseFile(file)) {
  console.log(event.timestamp, event.metric, event.value)
}
```

## Architecture

```text
ingest -> decode -> normalize -> event stream
```

## Event schema

```ts
type TelemetryEvent = {
  timestamp: number
  metric: string
  value: number | string | boolean | null
  unit?: string
  source?: string
  index?: number
}
```

## What this is NOT

- not a database
- not a realtime sync layer
- not a dashboard
- not a web app or plugin system
- not a storage engine

## Sample data

This package uses the real Garmin FIT sample in the repository root as the reference data file. If a real device file is unavailable in future, a synthetic generator can be added clearly labeled SYNTHETIC, but the current benchmark uses the actual Garmin binary.
